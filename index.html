Know your algorithms

Complexity at a glance for your DAA report and viva.

G

Greedy algorithm

Ranks resources by value-to-cost ratio and selects each resource if it fits the remaining budget.

TimeO(n log n)SpaceO(n)
DP

Dynamic Programming

Builds an optimal value table for each resource and each capacity, then backtracks to recover the selection.

TimeO(nB)SpaceO(nB)

B is the integer budget in scaled units. Dynamic Programming is pseudo-polynomial; this demo scales ₹ costs into budget units to keep computation practical.
